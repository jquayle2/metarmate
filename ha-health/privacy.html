Privacy Policy

Home Assistant Health — a private, single-household integration.

Who this covers

Home Assistant Health is used only by members of Jeff Quayle's household to connect a family member's Fitbit data, through the Google Health API, to a Home Assistant server that the household runs at home. It is not available to the public.

Data we access

With the user's permission, the app requests read-only access to Google Health data such as sleep sessions and stages, activity, and health metrics (for example heart rate). It does not request write access and never changes or deletes data in the user's Google account.

How the data is used

The data is used for one purpose: showing household members, on dashboards and announcements inside the home, how much the user has slept and whether she may need extra rest. It is not used for advertising, profiling, credit or lending decisions, or any purpose unrelated to that feature.

Where the data is stored

Data is stored only on the household's own Home Assistant server, on hardware in the home. OAuth tokens are stored in the same place. No copy is kept on any outside server operated by the developer.

Sharing

The data is never sold, rented or transferred to anyone. It is not shared with third parties, except as needed to run the household's own systems or as required by law. No people outside the household read it.

Google API Services User Data Policy

Home Assistant Health's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept on the household server for as long as the integration is in use. The user can stop access at any time by removing Home Assistant Health at myaccount.google.com/permissions, or by asking for the integration and its stored data to be removed from the household server using the contact below.
